# Product Requirements Document (PRD): Karhutla ML & Dashboard

- **Pengguna:** BPBD, Manggala Agni, kepala desa di sekitar gambut Kalimantan.
- **Masalah:** Peringatan dini sering datang setelah api kadung membesar; desa tanpa anggaran butuh sistem peringatan yang murah dan cepat.
- **User Story:** Sebagai petugas BPBD, saya ingin melihat sel gambut berisiko tinggi besok dan menerima pesan Telegram saat ada potensi ekstrem, supaya regu bisa disiagakan.
- **Acceptance Criteria:** Given prakiraan baru masuk, when dashboard terbuka, then peta berubah tanpa refresh dalam 3 detik.
- **Non-functional:** Peta termuat < 3 detik, probabilitas terkalibrasi dengan baik, tidak ada kunci rahasia di frontend.
