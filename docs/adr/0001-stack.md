# ADR-001: Pilihan Tech Stack

- **Konteks:** Membutuhkan sistem prediksi dan pemantauan realtime tanpa kompleksitas mengurus server sendiri.
- **Keputusan:** Menggunakan Supabase (PostgreSQL) untuk database & realtime, React + Vite + Leaflet untuk dashboard, serta Google Colab + Earth Engine untuk model ML.
- **Konsekuensi:** Terikat pada ekosistem Supabase, namun proses pengembangan jauh lebih cepat selesai dalam waktu singkat.
